# Dual-Port RAM Configuration

## Project Overview
Designed and implemented a **Dual-Port RAM (Random Access Memory)** using SystemVerilog, supporting simultaneous read and write operations through two independent ports. Verified memory access, data integrity, and read/write functionality through simulation and testbench validation.

## Key Features
- Independent dual-port memory access.
- Simultaneous read and write operations.
- SystemVerilog-based RTL design.
- Class-based testbench verification.
- Functional validation of memory read/write operations.

## Project Structure
- `design_code` – RTL design implementation.
- `classes and tb_code` – SystemVerilog verification classes and testbench.
- `Dual_Port_RAM_Verification_Project_Report.pdf` – Detailed project report.
- `Screenshot` – Simulation/project output.

## Tools & Technologies
- SystemVerilog
- RTL Design
- Functional Verification
- Simulation and Testbench

## Verification
The design was verified using a SystemVerilog testbench to validate read/write functionality, memory access, and data integrity.

## Objective
To understand and implement dual-port memory architecture and gain practical experience in RTL design and functional verification using SystemVerilog.
